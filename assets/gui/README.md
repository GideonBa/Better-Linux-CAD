# GUI startup artwork

`archimedes-lever.gif` is the user-provided Archimedes illustration used by the BLCAD startup
splash. The file content is retained unchanged; only its extension reflects the actual GIF encoding.

The curated desktop icons are vendored separately in `pixelarticons/`; see its README, MIT license,
explicit presentation catalog and source/checksum manifest. The startup artwork is independent of
the icon system.
